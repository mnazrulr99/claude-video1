## Effect & Transition

- **Fade masuk dari hitam** (0–0.8 s) + push-in lencana.
- Hard cut dominan; **1 split screen** (47.5 s); **dip hitam** sebelum kad akhir (70.2 s).
- Tiada punch-in digital ketara — variasi framing datang dari sudut kamera sebenar (wide ↔ close-up ↔ dalam kereta).

## Checklist cepat

1. Hook: close-up lencana/detail + soalan perbandingan ("Tak nak X, tapi nak Y?") ≤6 s (R45).
2. Lower third presenter + model + logo dealer pada kemunculan pertama presenter.
3. Setiap spec disebut → B-roll close-up bahagian itu (R1b/R37/R63); senarai spec dari transkrip (R84).
4. Subtitle frasa putih ±75–80% (atau karaoke R16/R62 — tanya R72).
5. Split screen bila dua benda berkait (skrin + kawalan).
6. CTA presenter → tagline → dip hitam → **kad akhir dealer** (R82b).
7. Puncak ≤ −1 dBTP.

**Bahan dari pengguna/klien:** raw presenter + B-roll setiap detail (enjin, roda, interior, butang, skrin), senarai spec, nama presenter, logo dealer, maklumat kad akhir (alamat, telefon, e-mel, sosial, URL), tagline.

## Checklist cepat

1. Tanya format (9:16/landscape) & muzik (R30, R44).
2. Logo/nama program tetap di atas (±9–14%, bukan zon UI).
3. Susun ikut aturcara: lokasi → aktiviti → momen teruja → klimaks (perlawanan) → hadiah.
4. Potong ikut beat ±0.6–1.2 s; take lebih panjang untuk penyampaian hadiah (R41).
5. Transition berbeza-beza (flash, panel, paper-rip) di pertukaran segmen; satu light leak penutup → hitam (R42).
6. Tiada SFX (R36); muzik −13/−14 LUFS, ≤ −1 dBTP.

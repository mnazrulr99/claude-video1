## Teks / Caption

| Item | Nilai |
|---|---|
| Caption karaoke | **Tiada** (tiada suara) |
| Gaya teks cerita | **Serif klasik kecil** (gaya Times/Cormorant), **sentence case**, putih + bayang sangat halus, tanpa kotak, tengah |
| Saiz | Cap-height ±18–20 px → font **≈26–30 px** pada 1080 (**terlalu kecil** — X5) |
| Kedudukan | Ayat cerita **±70–75% dari atas** (atas baju); senarai manfaat ±45–50% (sebelah tapak tangan) |
| Animasi | Muncul baris demi baris / menaip; "Day" → "Day 1" menaip |
| Label produk | **Skrip italic tulisan tangan putih** + **anak panah melengkung** ke produk, ±25–35% dari atas, sebelah tutup botol |
| Penanda masa | "Day 1", "Day 14" — serif putih lebih besar (≈44 px), ±75–80% |

## Effect & Transition

- **Hard cut** dominan (jump cut rutin).
- **Light leak / bloom putih-pink** sekali (43.8 s) — tanda lompat masa Day 1 → Day 14 (selari semangat R70: light leak untuk peralihan bermakna sahaja).
- Produk ditolak rapat ke lensa (selari R7).
- Filter ringan hangat (selari R64).

±5 SFX / 48 s, **hanya pada produk/grafik** (selari R48/R65). Kelantangan **−17.8 LUFS / +1.2 dBTP** — ikut R14.

## Checklist cepat

1. Hook = close-up masalah kulit + satu ayat formula ("makeup + sweat + oil = breakouts").
2. Reveal produk rapat ke lensa + chime.
3. Setiap produk: label skrip + anak panah → tekstur di tapak tangan → senarai manfaat bertitik.
4. Ayat cerita peribadi serif sentence case semasa demo (≥44 px — X5).
5. "Day 1" → light leak → "Day 14" (hasil sebenar, R37).
6. Penutup: kedua-dua produk di sebelah muka + ayat emosi ♡ → hitam (R12).
7. Audio: BGM lembut + chime pada produk sahaja, −13/−14 LUFS.

**Bahan dari pengguna/klien:** footage rutin (sebelum, langkah, tekstur), footage hasil hari ke-N (tarikh sebenar), nama produk tepat + senarai manfaat (dari jenama), BGM.

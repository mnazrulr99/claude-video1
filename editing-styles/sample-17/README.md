## Caption / Teks

| Item | Nilai |
|---|---|
| Caption karaoke | **Tiada** — maklumat disampaikan sebagai **teks langkah** (ringkasan, bukan transkrip) |
| Gaya teks langkah | **Sentence case**, sans regular/medium (font teks asli TikTok/IG), putih, bayang lembut, tanpa kotak, 1–2 baris |
| Penanda | Nombor langkah ("1.", "2.") dan **asterisk** untuk tip sampingan ("\*Put hair in…\*", "\*not on your hair like this\*") |
| Saiz | Cap-height ±30 px → font ≈42–44 px pada 1080 |
| Kedudukan | **±20–24% dari atas**, tengah — di atas kepala presenter demo, tidak tutup muka ✅ |
| Hook | "❌ I NEVER DO THIS…" — X merah + ALL CAPS putih, ±13% dari atas |

## Effect & Transition

- **Hard cut sahaja** pada lapisan B-roll; tiada zoom/blur/flash.
- Kesan utama = **komposit 2 lapisan** (presenter cut-out di depan, demo di belakang) — gaya "green screen" TikTok.
- B-roll demo dipilih supaya **sepadan dengan ayat** (rambut gugur → "shedding", sanggul → "floppy high bun", jubah → "wet hair").
- Contoh "salah vs betul" (0–6 s, 85–88 s) ditanda dengan **❌ / teks asterisk**.

## Checklist cepat

1. Hook = **kesilapan biasa** + "❌ …" di atas, B-roll cara salah (R45/R56).
2. Presenter cut-out (green screen / buang latar) di **bawah tengah ±55% tinggi**, bercakap sepanjang video.
3. B-roll demo bertukar ±3–4 s, **setiap klip sepadan dengan ayat** (R37); contoh salah ditanda.
4. Kad title siri berjenama (serif + latar warna jenama) selepas hook; papan produk jika ada cadangan produk.
5. Teks langkah bernombor sentence case di atas (±22%), asterisk untuk tip sampingan; jangan tutup muka (R1).
6. Akhir: CTA siri seterusnya ("stay tuned…") + teks "coming soon!" → fade/cut hitam (R12).
7. Audio: suara sahaja, −13/−14 LUFS, ≤ −1 dBTP (R14).

**Bahan dari pengguna/klien:** (a) klip presenter bercakap ke kamera **di depan latar rata/green screen** (atau izin Claude buang latar),
(b) footage demo setiap langkah (termasuk contoh salah), (c) nama siri/jenama + warna jenama untuk kad title, (d) senarai produk + gambar (jika papan produk).

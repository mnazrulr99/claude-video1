## Checklist cepat

1. Pilih effect ikut fungsi momen (hook → orbit/cover story; langkah → checklist; statistik → chart grow; reveal → pull-back).
2. Maks 1–3 effect khas setiap video biasa (X10), selebihnya hard cut.
3. Title gaya "cover story"/teks belakang subjek perlukan cut-out (rembg) — semak kualiti tepi.

**Bahan dari pengguna/klien:** footage presenter (latar kemas memudahkan cut-out), screenshot/UI/berita jika guna headline wall/phone mockup, data untuk chart grow.
